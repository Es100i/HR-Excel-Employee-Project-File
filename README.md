# HR-Excel-Employee-Project-File
This project was carried out to determine the personal information of the staffs of a certain Human Resources company to determine how well they relate in their work environments displaying the total employee turnover, salaries, combination of the two genders and maximum salary for the department in various cities in Nigeria. 

 **TOOLS USED:**
 
 - Microsoft Excel and Excel Functions

**HOW TO USE:**

 - Download the file : HR Excel Employee Project File. xlsx
 -  Open in Excel file and view how the employees from different departments data was analyzed.
